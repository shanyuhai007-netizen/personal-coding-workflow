# 视觉专项适配（pc-visual-1）

本协议是 personal-coding 对外部 ui-taste-loop 的接入方式。先读实际组件原文，以本协议记录步骤差异；不修改、捆绑或自动下载上游技能。

## 触发与范围

每个前端任务明确判断并记录 `ui` 与 `visual_change`，不得因可选事实默认 false 而漏填。`ui` 表示 HTML/CSS/客户端 JS；`visual_change` 表示新建用户界面或改变布局、字体、配色、视觉组件。纯逻辑任务为 false。已有页面补视觉验收仍为 true，即使 implementation_complete=true。

局部视觉修复也进入视觉阶段，但方向与现有合格证据可核验后 reuse；只检查影响范围，不强制重做全站。未变动的业务状态沿用证据须核对当前适用性。

## 方向、实现与预算

visual-direction 在平台指导后执行 ui-taste-loop 与 frontend-design。已批准品牌、方向、组件库直接复用；仅新方向需要 Discover，四方向是探索选项数量，不是固定页面数。项目已有偏好足以决定可逆方案时 Agent 推荐并推进；只有真实偏好缺口或承诺冲突才问人。大探索可用 prototype，但不在弃用原型上跑完整品质循环。

开始前固定用户任务、视觉约束、页面/状态/viewport、主题、数据和字体加载条件。记录上限：项目预算优先；未约定时最多两次修复轮（初评后最多两次修改再评）。这是保守默认值，不是效果已验证的最佳阈值；同时遵守现有费用授权。max_attempts 仅计回执失败，不能替代视觉预算。

有行为变化仍用 implement/TDD；纯视觉用 visual-build，相称检查即可。已有实现核验后可 reuse，不能因 implement 被跳过而省掉视觉验收。动效或交互打磨按需执行 emil-design-eng，明确 UI 审计按需执行 web-design-guidelines，均记录实际产物。

## 独立比较与收口

运行界面并确认必要行为可用后截图。critic 使用 fresh context，提供实际像素、简短用户任务、固定约束和已裁决例外，不提供实现理由、历史评分或目标分数。初评看当前版；后续比较同一场景的旧版与新版，实际页面数量决定集合。保留缺陷/裁决/偏好分类、逐页判决及原始回应；必要时匿名展示并交换顺序复核。

分数只供记录，9/10 或 8.5±0.5 均不作完成门槛。必须同时满足：约定场景已覆盖、必需缺陷已修复或经有权裁决接受、无重要回退、最终视觉目标有具体观察支持。多数页更好或无新增缺陷不能单独证明通过。连续两轮持平/更差或预算耗尽即停止修复并记录；仍有必需条件未满足则保持未完成，报告最佳候选与需要的决定。

Phase 3 减法、AI Tells 与适用 Copy Audit 在最终证据固定前完成。改变布局、文案换行或层级后重新截图并复验受影响部分，不能沿用修改前 critic 通过。纯静态截图盲区交给运行交互验证，不以豁免替代。最终 verify 和代码双轴评审在视觉修改之后；触碰行为时复跑受影响行为检查。

真实数字/客户/机制优先引用可查证的项目材料，不编造；只有无法查到的业务事实才由用户补齐。产品微文案依 frontend-design，营销 Copy Audit 仅在适用时执行并记录不适用理由。

## 工具与证据

先查当前工具清单与已安装技能目录；当前端目录缺组件时，继续查本机其他宿主的技能根目录，找到可读原文可按 read 复用，不为跨端使用复制独立版本。在 component_sources 注册实际可读 ui-taste-loop 与 frontend-design 原文路径。宿主无原生接口但文件可读时按 read 执行，不能声称原生发现。无截图、视觉输入或独立上下文能力则记录限制，必要视觉条件保持未满足。

impeccable 使用已验证版本、明确扫描目标，保存原命令/退出码/日志及例外。检测通过仅证明所扫规则未发现对应问题，不代表高品味；扫描不可执行时显式记录替代审计和失去的保障。以真实运行版本核对退出码含义，不硬编码上游规则数量。

沿用事件、receipt、artifact、conditions 与 acceptance 总账。保存方向复用依据或探索结果、预算、截图与对应树/运行环境、每轮独立会话标识及输入输出、修复/拒绝理由、未决缺陷、审计与真值来源、最终截图。visual-review 使用完整树身份；回执 independent 字段不证明每轮上下文隔离，需原始记录支持。最终语义质量由评审负责，工具只校验声明与证据一致性。

规则改变后旧任务按 EXECUTION 的规则迁移限制处理。首次真实 UI 票验证本适配的耗时、人工介入和用户偏好，尚不能宣称稳定改善品味。
